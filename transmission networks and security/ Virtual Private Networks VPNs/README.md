Описание задания:
Описание задачи.
В рамках данного задания вы получите практический опыт использования самого популярного Open Source решения для организации VPN — OpenVPN.

Справка. OpenVPN предлагает два виртуальных устройства: TUN (только IP-трафик) и TAP (любой трафик). Соответственно, для приложений всё выглядит так, как будто оно использует не обычный Ethernet-интерфейс, а другой, направляя через него трафик. OpenVPN шифрует данный трафик и перенаправляет его через Ethernet-интерфейс.

Поднимите две виртуальные машины: Ubuntu с Адаптер 1 — NAT и Адаптер 2 — Internal Network и Kali с Адаптер 1 — NAT и Адаптер 2 — Internal Network.
Установите на обеих машинах OpenVPN.
Дополнительно на Ubuntu установите сервер openssh, а на Kali — mc.
Откройте в Kali Wireshark и выберите интерфейс eth1. Для тестирования используйте утилиту netcat (она позволит прослушивать на сервере определённый порт, а с клиента — подключаться к этому порту).
Ubuntu: прослушиваем порт 3000.
Kali — подключаемся через туннель к порту 3000 сервера. Передаём любой текст, он будет отображаться на сервере в консоли.
Удостоверьтесь в Wireshark, что данные передаются в открытом виде (Follow TCP Stream). Сделайте скриншот.
Снегерируйте ключ и безопасно передайте ключ с сервера на клиент.
Удостоверьтесь в Wireshark, что данные не передаются в открытом виде (Follow UDP Stream). **Сделайте скриншот. **
Ожидаемый результат от выполнения задания:
Между двумя хостами установлено VPN-соединение, данные передаются в зашифрованном виде.
